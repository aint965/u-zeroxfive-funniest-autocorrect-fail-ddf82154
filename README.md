Entry for the [Funniest Autocorrect Fail](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154) competition on make.fun.

`main.py` writes exactly one line to `/output/entry.txt`: a short text message
in which autocorrect swaps "pasta" for "pastor", turning a grocery run into
an awkward dinner invitation. The intended word is instantly clear from the
mention of spaghetti, and the line reads like a real text-message slip.

Run it with:

```sh
python3 main.py
```
